## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- OpenAI API key
- Git

### Setup

```bash
# Clone or download this repository
git clone https://github.com/sravanml/AI-Agents-Foundations.git
cd AI-Agents-Foundations

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create .env file
cp .env.example .env
# Add your OpenAI API key to .env
```

### Run Chapter 1 Example

```bash
cd chapters/01-langchain-basics
python3 main.py
```

You should see a summary of Elon Musk generated by the LLM!

## ❓ FAQ

**Q: Do I need a GPU?**  
A: No. All computations run on OpenAI's servers. You just need internet.

**Q: How much will this cost?**  
A: Very little. The examples use GPT-4 but with small inputs. Budget ~$5-10 for the entire course.

**Q: Can I use a different LLM?**  
A: Yes! LangChain supports Claude, Llama, Cohere, and more. Just swap the LLM provider.

**Q: How long does each chapter take?**  
A: 2-3 hours if you actively code along. Longer if you experiment.
